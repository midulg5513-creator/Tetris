# 俄罗斯方块游戏

这是一个使用Python和Pygame开发的俄罗斯方块游戏，包含基本的游戏功能和一些特色元素。

## 功能特性

- 完整的俄罗斯方块游戏逻辑
- 支持方块移动、旋转和加速下落
- 分数系统和等级提升
- 下一个方块预览
- 操作说明界面
- 特殊炸弹方块，可以清除周围的方块
- 游戏暂停和重新开始功能

## 安装与运行

### 前提条件

- Python 3.x
- Pygame库

### 安装依赖

```bash
pip install pygame
```

### 运行游戏

```bash
python 俄罗斯方块.py
```

## 操作指南

- **←/A**：向左移动方块
- **→/D**：向右移动方块
- **↑/W**：旋转方块
- **↓/S**：加速下落
- **空格**：直接落下
- **P**：暂停/继续游戏
- **R**：重新开始游戏

## 游戏特色

- **炸弹方块**：随机生成的特殊方块，可以清除周围8个格子的方块
- **等级系统**：每消除10行，等级提升，下落速度加快
- **分数系统**：根据消除的行数获得不同的分数
- **美观的界面**：包含游戏区域、侧边栏和操作说明
